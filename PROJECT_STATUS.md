**---**



**# Important Architectural Decisions**



**- Guest browsing is allowed.**

**- Login is required before Checkout.**

**- Business data must never be hardcoded.**

**- Always consume real backend data whenever available.**

**- CSS must remain modular.**

**- JavaScript must remain modular.**

**- One page-specific CSS file when needed.**

**- One page-specific JavaScript file when needed.**

**- Shared functionality belongs in reusable components.**
